Selected guarantees:
- Accepted revised books are well typed and satisfy the original liveness check.
- Revised typing is stable under well-typed substitution and instantiation.
- Original parallel reduction, runtime evaluation, and runtime traces preserve revised typing.
- Typed eta factorization and rigid-type exposure have no open simulation assumption.
- Closed typed terms have progress under book typing and liveness assumptions.
- A value at a formed Data type satisfies the original Data predicate.
- Joined values at the same revised type have equivalent Data classification.
- A checked definition retains its declared type along original runtime traces.
- Closed live terms cannot have the empty enumeration type in a well-typed live book.
- An accepted book has no definition whose declared type is joined to Empty.
- Accepted text parses to such an accepted book.

Limits:
- These are the historical revised checker guarantees, not a port of every later kernel theorem.
- The result does not prove safe.ts translation correctness or source-checker soundness.
- It does not prove comparison completeness or adequacy of a fixed fuel bound.
- It does not prove parsing against an independent text specification.
- It does not prove native compiler correctness or runtime performance.
- Exact quantity-sensitive typing need not survive arbitrary eta contraction.
- Eta is used in comparison; original runtime reduction remains in the safety theorems.
- Erasure retains All, Sig, Tup, and Let quantity tags.
- Data classification equivalence requires values at the same revised type.
